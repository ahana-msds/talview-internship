Chapter 1: Basic HTML Elements

1. Headings (h1 - h6)

Headings help structure the content hierarchy.

This is H1 (Main Title)

This is H2 (Section Title)

This is H3 (Sub-section)

This is H4

This is H5
This is H6 (Smallest)

2. Paragraphs & Text Formatting

The <p> tag defines a paragraph of text.

You can use strong for bold, em for italics, and mark for highlighting.

Line breaks are done with the <br> tag.
This line is below a break.

3. Links (Anchor Tag)

The <a> tag creates hyperlinks.

Absolute Link: Go to Google (Opens in new tab)

Relative Link: Stay on this page (Relative)

4. Images

The <img> tag embeds images. It needs src and alt attributes.

Note: Always provide 'alt' text for accessibility.
