
# typescript dom interaction and fetch demo

this folder contains a small browser-based demo built using typescript that shows how to interact with html elements, handle button clicks, and update the webpage dynamically after compiling typescript to javascript.

---

## objectives

* understand how typescript works with the browser dom
* learn how to select and update html elements using typescript
* practice handling user events like button clicks
* understand the typescript to javascript compilation workflow

---

## topics covered

* dom element selection using getelementbyid with proper typing
* event handling using addeventlistener in typescript
* updating text content dynamically based on user input
* basic input handling and validation logic
* compiling typescript into browser-compatible javascript
* configuring compiler behavior using tsconfig.json

---

## files overview

| file name       | purpose                                                                           |
| --------------- | --------------------------------------------------------------------------------- |
| `index.html`    | defines the ui for candidate check-in with input, button, and result text display |
| `main.ts`       | contains typescript logic for handling dom events and updating the ui             |
| `main.js`       | compiled javascript output generated from main.ts for browser execution           |
| `tsconfig.json` | typescript compiler configuration with strict type checking options               |

---

## what i learned by implementing these

* how typescript enforces safer dom access through typing
* how browser events are connected to functions in scripts
* how user input flows from html to javascript logic
* how compilation is required before running typescript in browsers
* how tsconfig settings affect output and strictness of code

---

## summary

* typescript improves reliability of dom-based javascript programs.
* event listeners connect user actions to application logic.
* compiled javascript is what actually runs in the browser.
* understanding dom interaction is essential for frontend development.
