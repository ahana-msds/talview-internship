

# typescript basics and function concepts

this folder contains practice programs written in typescript to understand core language features such as variables, data types, functions, arrow functions, and parameter handling.

---

## objectives

* understand how variables and data types work in typescript
* learn how to write and use functions with proper typing
* practice arrow function syntax
* understand optional and default parameters in functions

---

## topics covered

* variable declarations using let and const
* basic data types like number, string, boolean, and arrays
* function declarations with typed parameters and return types
* arrow functions and their concise syntax
* optional parameters using ?
* default parameter values in functions
* basic logical and arithmetic operations for practice

---

## files overview

| file name              | purpose                                                      |
| ---------------------- | ------------------------------------------------------------ |
| `variables.ts`         | practice examples for variable declarations and basic typing |
| `basics.ts`            | covers basic operations and fundamental typescript syntax    |
| `functions.ts`         | demonstrates normal function declarations with types         |
| `arrowfunction.ts`     | shows arrow function syntax and usage examples               |
| `optionalparameter.ts` | demonstrates how to use optional parameters in functions     |
| `defaultparameter.ts`  | shows how default values work in function parameters         |
| `practice.ts`          | mixed practice problems combining multiple concepts          |

---

## what i learned by implementing these

* how typescript enforces type safety at compile time
* how function inputs and outputs can be strictly typed
* how arrow functions reduce boilerplate syntax
* how optional and default parameters make functions flexible
* how early error detection improves code reliability

## summary

* typescript builds on javascript by adding strong typing.
* functions are core building blocks of program logic.
