

# dom testing and typescript fundamentals in javascript

this folder contains practice code for testing dom interactions using jest and jsdom, along with typescript examples to understand core javascript and typescript concepts like variables, functions, parameters, and async iteration.

---

## objectives

* learn how to test dom manipulation using jest and jsdom
* understand how typescript compiles to javascript for browser usage
* practice core javascript and typescript syntax and typing
* understand iteration patterns using generators and async generators

---

## topics covered

* dom testing using jest and jsdom environment
* selecting elements using getelementbyid and updating textcontent
* handling events like button clicks in tests and real dom
* variables and basic types in typescript
* functions, arrow functions, optional and default parameters
* generators and advanced iteration patterns
* async generators for handling asynchronous data streams

---

## summary

* dom testing ensures ui logic works as expected before deployment.
* typescript adds reliability to javascript through static typing.
