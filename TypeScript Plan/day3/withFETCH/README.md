
# typescript dom and fetch api demo

this folder contains a small web demo built using typescript that demonstrates how to interact with the dom, handle user input, and fetch and display dynamic data on a webpage.

---

## objectives

* understand how typescript works with browser dom apis
* learn how to handle button click events using typescript
* practice fetching data and displaying it dynamically
* understand how typescript compiles to browser-compatible javascript

---

## topics covered

* selecting dom elements using getelementbyid with type assertions
* handling click events using addeventlistener
* updating text content based on user input
* using fetch api to retrieve data asynchronously
* rendering list items dynamically in the dom
* configuring typescript using tsconfig.json

---

## files overview

| file name       | purpose                                                                 |
| --------------- | ----------------------------------------------------------------------- |
| `index.html`    | defines the ui for candidate check-in and assessment list display       |
| `main.ts`       | contains typescript logic for dom handling and fetch operations         |
| `main.js`       | compiled javascript output generated from main.ts for browser execution |
| `tsconfig.json` | typescript compiler configuration for dom and es2017 support            |

---

## what i learned by implementing these

* how to safely access dom elements using typescript types
* how asynchronous fetch calls update the ui after data loads
* how event-driven programming works in browser environments
* how typescript compilation is required before running code in the browser
* how strict compiler settings improve code reliability

## summary

* dom manipulation and fetch are core frontend skills.
