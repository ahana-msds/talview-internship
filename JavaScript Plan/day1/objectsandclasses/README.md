# javascript objects, arrays, and classes 

this folder contains practice files created to understand how javascript handles structured data using objects and arrays, and how modern es6 classes are used to model real-world entities and services.

---

## objectives

- understand how to create and manipulate objects and arrays
- learn how references, copying, and memory behavior work in javascript
- understand object methods, constructors, and the use of this
- learn how es6 classes structure reusable and scalable code

---

## topics covered

- object creation and property access
- object references, shallow copy, and deep copy
- garbage collection and memory concepts
- object methods and the this keyword
- constructor functions and the new operator
- optional chaining and symbol data type
- object to primitive conversion
- arrays and array methods
- nested objects and arrays
- es6 class syntax and constructors
- class inheritance and method overriding
- static properties and methods
- private and protected class members
- extending built-in classes
- instance checking using instanceof

---

## files overview

| file name | concept covered |
|--------|------------------|
| `objects.js` | detailed object concepts including references, copying, symbols, and conversions |
| `objectsdetailed.js` | advanced object behaviors, memory handling, and method usage |
| `objectsandarrays.js` | combined usage of objects and arrays with iteration and manipulation |
| `classes.js` | es6 class syntax, inheritance, static methods, private fields, and instanceof |

---

## what i learned by implementing these

- how objects are stored and passed by reference, not by value
- why shallow copy fails for nested structures and when deep copy is needed
- how this behaves inside object methods and class methods
- how constructors and classes help model real-world systems
- how inheritance reduces code duplication and improves structure
- how modern javascript uses classes heavily in frontend and backend systems

---

## summary 

objects and arrays are core structures used to represent real-world data in javascript.  
references and copying behavior affect how data changes across different variables.  
classes provide a clean and scalable way to organize related data and behavior.  
strong understanding of these concepts is essential for building large applications.
