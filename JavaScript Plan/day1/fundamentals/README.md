# javascript fundamentals 

this folder contains hands-on practice files created while learning core javascript concepts as part of the internship roadmap and self-study plan.

---

## objectives

- understand how javascript handles data, logic, and functions
- learn how programs control execution using conditions and loops
- practice writing reusable and readable functions
- build confidence in using core language features before moving to dom and async concepts

---

## topics covered

- variables and scoping using var, let, and const
- primitive and non-primitive data types
- operators and expressions
- conditional statements and loops
- functions, parameters, return values, and scope
- arrays, objects, and built-in data methods

---

## files overview

| file name | concept covered |
|--------|------------------|
| `variables.js` | variable declaration and scope differences |
| `operators.js` | arithmetic, comparison, logical, and unary operators |
| `conditions.js` | if/else, switch, loops, break and continue |
| `functions.js` | function declaration, parameters, scope, return values |
| `datatypes1.js` | primitive data types and basic methods |
| `datatypes2.js` | arrays, objects, maps, sets, destructuring, date |

---

## what i learned by implementing these

- how data types affect program behavior and comparisons
- how control flow decides which part of code executes
- how functions help structure logic and avoid repetition
- how arrays and objects store and organize real-world data
- how small mistakes in types and conditions can change outputs
- how writing code manually improves understanding of execution flow

---

## summary of understanding 

javascript programs are built using variables, conditions, and functions working together.  
data types and operators control how values are processed and compared.  
functions help organize logic and make code reusable and readable.  
strong fundamentals are necessary before working with dom, apis, and frameworks.
