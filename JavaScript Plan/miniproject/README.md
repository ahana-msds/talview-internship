# weather dashboard simulator 

this folder contains a mini interactive weather simulator built to practice dom manipulation, user input handling, ui state management, and simulated async data flow in a realistic frontend-style application.

---

## objectives

- understand how to connect user input with dynamic ui updates
- practice showing loading, success, and error states on the screen
- learn how to structure javascript logic for better readability
- apply css styling for layout, animations, and feedback

---

## topics covered

- selecting and updating dom elements dynamically
- handling click events and user input validation
- showing and hiding elements using css classes
- simulating api-style workflows with loaders and delays
- updating multiple ui fields from javascript
- managing simple search history in the ui
- using css animations for better user experience

---

## files overview

| file name | purpose |
|----------|--------|
| `index.html` | defines the full ui structure including search input, results area, loader, error box, and history list :contentReference[oaicite:0]{index=0} |
| `style.css` | provides glassmorphism layout, animations, responsive grid, and state-based styling such as loader and error display :contentReference[oaicite:1]{index=1} |
| `app.js` | controls all application logic including event handling, data simulation, ui updates, and history management |

---

## what i learned by implementing these

- how frontend apps manage different ui states like loading, error, and success
- how to update multiple dom elements from a single user action
- how css and javascript work together to reflect application state
- how user experience improves with visual feedback like loaders and animations
- how small frontend projects resemble real dashboard workflows in production systems

---

## summary 

- interactive web apps depend on dynamic dom updates and event handling.  
- ui state management is essential for showing loading and error feedback.  
- structured javascript improves maintainability as features grow.  
- this pattern is common in real-world dashboard and analytics interfaces.
