# dom manipulation in javascript 

this folder contains a small interactive task list application built to understand how javascript interacts with html elements and updates the webpage dynamically using the document object model (dom).

---

## objectives

- understand how javascript selects and modifies html elements
- learn how to handle user interactions using event listeners
- practice creating and inserting elements dynamically
- apply css classes through javascript for visual feedback

---

## topics covered

- selecting elements using getelementbyid
- handling button click events using addeventlistener
- creating elements using createelement
- updating text using innertext
- appending elements using appendchild
- toggling css classes using classlist
- basic input validation

---

## files overview

| file name | purpose |
|----------|--------|
| `index.html` | defines the structure of the task list ui including input box, button, and task container :contentReference[oaicite:0]{index=0} |
| `script.js` | contains all javascript logic for adding tasks, handling clicks, and updating task styles dynamically |

---

## what i learned by implementing these

- how javascript can dynamically change webpage content without reloading
- how user actions trigger functions through event listeners
- how new html elements can be created and attached at runtime
- how css classes can be added or removed to reflect state changes
- how small validations prevent incorrect user input
- how dom-based logic forms the base of frontend development

---

## summary 

- the dom allows javascript to interact directly with webpage elements.  
- events connect user actions with program logic.  
- dynamic element creation enables interactive web applications.  
- dom manipulation is the foundation of all frontend frameworks.
