# candidate evaluation dashboard 

this folder contains a mini dashboard built to simulate how candidate data can be fetched, evaluated, and displayed dynamically using javascript, similar to real hr-tech and ai assessment platforms.

---

## objectives

- understand how dom manipulation and api data work together
- practice fetching and rendering dynamic content on a webpage
- apply basic ui styling for readability and feedback
- structure logic using functions and simple service-style patterns

---

## topics covered

- selecting and updating dom elements dynamically
- handling button click events
- fetching data from external apis
- looping over api responses to create ui cards
- conditional styling based on evaluation score
- basic separation of ui and logic responsibilities

---

## files overview

| file name | purpose |
|----------|--------|
| `candidate.html` | defines the dashboard structure with heading, load button, and result container :contentReference[oaicite:0]{index=0} |

| `app.js` | handles fetching candidate data, generating evaluation scores, and rendering cards dynamically |

## what i learned by implementing these

- how frontend applications consume data from external services
- how javascript dynamically creates and inserts ui components
- how event-driven programming connects user actions to logic
- how simple visual feedback improves user understanding
- how small dashboards reflect real product workflows in ai systems

## summary

dynamic dashboards combine dom manipulation with api communication.  
user actions trigger data pipelines and ui updates.
